# ☕ Java Programs

| **S.No.** | **Program Name** | **Description** |
|---|---|---|
| 1 | `ArmstrongNumber.java` | Checks whether a given number is an Armstrong number. |
| 2 | `StringReversal.java` | Reverses a given string using a loop. |
| 3 | `PowerOfNumber.java` | Calculates the power of a number using repeated multiplication. |

### How to Run

Open the Java folder in the terminal and execute:

```bash
javac ArmstrongNumber.java
java ArmstrongNumber
```

Replace the filename and class name to run the other Java programs.

# 📘 TypeScript Programs

| **S.No.** | **Program Name** | **Description** |
|---|---|---|
| 1 | `SumOfDigits.ts` | Calculates the sum of the digits of a given number. |
| 2 | `FetchUserData.ts` | Fetches user information from an API using async/await and the Fetch API. |
| 3 | `RemoveSpacesFromString.ts` | Removes spaces from a given string using the replace method. |

### How to Run

First, compile the TypeScript program:

```bash
tsc SumOfDigits.ts
```

Then execute the generated JavaScript file:

```bash
node SumOfDigits.js
```

For the Fetch API program:

```bash
tsc FetchUserData.ts --target ES2022 --lib DOM,ES2022 --module commonjs
node FetchUserData.js
```
